# v0.6.4.2 — clearer incoming progression readout (unreleased)

The seed-size card now separates checks on the progression surface from the live
foreign-progression placement ceiling. Changing Incoming Progression Confinement
updates the second count immediately. The surface itself stays the same. Intermediate
percentages select foreign item names; they do not remove a fraction of locations.
The side readout uses the same rule and respects Multiworld Scope overrides.

This correction is live on the beta website. Refresh the builder to see it.
No new YAML, seed, APWorld or client is required for this display correction;
placement behavior and existing seeds are unchanged. The v0.6.4.1 offline tools
retain the older readout. Source integration awaits the next release window.
