# v0.4.14 — release blurb (draft)

_Draft. Written as the window fills, not at tag time — the moment a change lands is the
only moment anyone remembers why it mattered._

## What you need to update

- **Client:** Required — use the v0.4.14 client with v0.4.14 seeds.
- **APWorld:** Host-only — the room host or generator must install v0.4.14; joining players only
  need the matching client.
- **YAML:** **No new YAML required. Existing YAMLs remain valid.**
- **Existing seed/save:** Compatible — keep an active v0.4.13 seed on its matched v0.4.13 pair.
  There is no save migration; just do not mix client and APWorld versions.
- **Profile/assets:** No action — no profile or packaged asset changed when the window opened.

## What is in it so far

Nothing yet. This window was opened at the v0.4.13 tag with zero commits past it, in the same
change that promoted stable to v0.4.13; nothing was carried over.

## What carried over from v0.4.13

Nothing — v0.4.13 shipped everything it documented (the retroactive corpse-award sweep, the shop
repaint, the tracker resize fixes, the opt-in pickup cue).
