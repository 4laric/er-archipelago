# v0.4.13 — release blurb (draft)

_Draft. Written as the window fills, not at tag time — the moment a change lands is the
only moment anyone remembers why it mattered._

## What you need to update

- **Client:** Required — use the v0.4.13 client with v0.4.13 seeds.
- **APWorld:** Host-only — the room host or generator must install v0.4.13; joining players only
  need the matching client.
- **YAML:** **No new YAML required. Existing YAMLs remain valid.**
- **Existing seed/save:** Compatible — keep an active v0.4.12 seed on its matched v0.4.12 pair.
  There is no save migration; just do not mix client and APWorld versions.
- **Profile/assets:** No action — no profile or packaged asset changed when the window opened.

## What is in it so far

Nothing yet. This window was opened in the same change that promoted stable to the v0.4.12
hotfix tag; nothing was carried over.

## For whoever writes the real one

The v0.4.3 blurb is the model: lead with what changed at the table, not with the option
name. The v0.4.11 blurb's "the shelf finally tells you what it's selling" and v0.4.12's "the
shelf un-padlocks" are the same shape — say what a player will feel before what was built.
