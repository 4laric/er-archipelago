# Player review notebook

The player review page includes all 4,925 locations, including those already confirmed by project sources. Search by item or place, choose an area, or work through the list with Next location.

## Enter existing notes

Select a location and paste your original notes into **Paste your existing notes**. The other fields are optional. Add your finding, route, corrections, or evidence links when useful. Mark **I have reviewed this location** when you have finished reviewing it. **My progress** filters your own work independently of project confirmation.

Notes save automatically in this browser on this device. Use one editing tab. Watch the save status; if storage fails, keep the tab open and download a backup before leaving. Clearing browser data can remove your notebook.

## Back up and share

Use **Download all notes / backup** regularly and at the end of each session. Keep the JSON file somewhere safe and share it with the maintainer when ready. Nothing is submitted automatically.

**Import notes or restore backup** accepts these notebook files and earlier player-review JSON files (a single report or an array). Preview the entries first. Different existing notes are kept unless you explicitly choose replacement; previous notes remain in recovery history.

For notes in Discord, text documents, or mixed formats, paste them into the matching location. The importer does not guess which similar pickup a note describes.

Catalog updates carry notes forward only when the location ID and full original name match. Conflicting or unmatched older records remain available through recovery downloads and the full backup.

Player observations and your personal reviewed status do not automatically change project confirmation. A maintainer still reviews the evidence.
